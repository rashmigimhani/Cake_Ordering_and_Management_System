# Cake_Ordering_and_Management_System

This is our 2nd Year 2nd Semester ITP Project, which is a “Cake Ordering and Management System” for "SWEET BLISS CAKES", designed to streamline the process of ordering, managing, and delivering cakes.

Through this application, we aim to connect customers with SWEET BLISS CAKES by providing an easy-to-use e-commerce platform where they can browse, customize, and purchase cakes online. At the same time, the system helps administrators manage orders, inventory, suppliers, and delivery schedules efficiently.

The application is developed using MERN Stack (MongoDB, Express, React, Node.js) technology.
